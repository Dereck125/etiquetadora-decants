# Logos nuevos

Para agregar el logo de una marca a la app:

1. En GitHub entra a esta carpeta (`logos-nuevos`) en la rama **develop**.
2. Toca **Add file → Upload files** y arrastra la imagen (PNG, JPG, WEBP o SVG).
3. **Nombra el archivo igual que la marca** en el catálogo, por ejemplo `Lattafa Perfumes.png` o `Rasasi.jpg`.
   Si la marca ya tiene logo, se reemplaza.
4. Toca **Commit changes** (deja marcado "Commit directly to the develop branch").

En 1 o 2 minutos GitHub convierte el logo a blanco y negro, lo agrega a la app de pruebas (`/dev/`) y abre
un **Pull Request a master**. Al aceptarlo, el logo queda en la app normal para todos los teléfonos.
